# microSwarm

An experimental artificial-agent simulation built from scratch in Kotlin.

Agents exist in a shared environment where they compete for resources, interact socially, reproduce, and learn from the consequences of their actions. Behaviour is driven by a custom neural learning system implemented without an ML framework.

### Features

* Custom neural network and learning system
* Plastic weights, eligibility traces and prediction-error learning
* Learned movement, targeting and social behaviour
* Individual agent memory and relationships
* Reproduction with neural weight inheritance
* Spatial partitioning for efficient agent interaction
* Phased multithreaded simulation loop

### Status

Experimental and no longer actively developed. This repository represents the latest stable state of the project.
